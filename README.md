# Data_Analysis_power-bi_Dashboard
Ride Booking &amp; Revenue Analysis Dashboard | Power BI Developed an interactive Power BI dashboard to analyze booking performance, revenue, distance metrics, vehicle trends, and rider/driver ratings. Created KPI-driven monthly and quarterly analysis with filters to identify booking trends, cancellations, payment methods, and rider behavior.
